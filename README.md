# Nokia 3310 — карманный 2000-й

Автономное Android-приложение с русским интерфейсом: корпус телефона, пиксельный LCD, Змейка, редактор SMS и синтезированный Nokia Tune с частотным визуализатором. Без рекламы, сервера и сетевых разрешений. Это неофициальная ретро-стилизация.

## Скачать и установить

`dist/Nokia3310.apk` — подписанная демонстрационная сборка для Android 6.0+ (API 23), target API 35. Перенесите файл на телефон, откройте и разрешите установку из выбранного источника. Для звука нужна громкость мультимедиа. Нужен обновлённый Android System WebView (проверена версия 74). Сборка подписана демонстрационным ключом, не предназначенным для Google Play.

## Управление

Средняя клавиша с синей чертой — выбрать / начать / пауза / сохранить. C — меню. Стрелки справа — выбор пункта.

- Змейка: 2 вверх, 4 влево, 6 вправо, 8 вниз; работают также свайпы. Края поля соединены. Столкновение с телом завершает игру. Рекорд сохраняется.
- SMS: цифровые кнопки с повторными нажатиями (800 мс), 0 — пробел, 1 — пунктуация, * — удалить, # — регистр. Можно коснуться поля и использовать клавиатуру Android. До 160 символов, автоматическое сохранение и явное сохранение средней клавишей. Реальной отправки SMS нет.
- Рингтоны: средняя клавиша запускает/останавливает синтезированный мотив Gran Vals. Столбики показывают частоты звука через Web Audio FFT. Воспроизведение и FFT используют один AudioBufferSource, без потока HTML media.

## Видео и проверка Android

`dist/Nokia3310-Android-demo.mp4` — новая запись экрана официального Android Emulator, AOSP Android 10 / API 29, x86_64. Показаны системные сведения о приложении, работа установленного APK, Змейка, сохранённое SMS, клавиатура Android и рингтон. Источник изображения и звука — сам эмулятор; исходный WAV отдельно в эту запись не подмешивается. Управление при записи автоматизировано через ADB и DevTools установленного Android WebView. Технические паузы сокращены при монтаже, задержка аудио/видео эмулятора скорректирована. Физический телефон недоступен, проверка выполнена именно на эмуляторе.

Предыдущий `dist/Nokia3310-demo.mp4` был браузерной демонстрацией и заменён новой записью Android.

Установлена сборка 1.2 (versionCode 3), без флага DEBUGGABLE. Проверены открытие Activity и основного экрана, управление игрой, очки, пауза, редактор SMS, восстановление черновика после завершения процесса и обновления APK, открытие системной клавиатуры и воспроизведение рингтона. Проверки роста змейки, разворота, столкновения и SMS multi-tap также выполнены в Android WebView на диагностической сборке с теми же ресурсами. Диагностическая сборка не распространяется.

На Android 15 программная эмуляция CPU оказалась нестабильной: перезапуск system_server и зависания системного WebView. Успешное прохождение Android 15 не заявляется. Для виртуального GPU в тестовом окружении отключены GPU rasterization и OOP rasterization через файл webview-command-line; APK использует обычную аппаратную композицию WebView. Для старого WebView добавлен fallback высоты экрана через vh.

## Сборка

Исходники в `app/src/main`. Java Activity использует WebView и отдаёт упакованные ресурсы через локальный HTTPS origin без реального сетевого подключения. Входящие системные отступы учитываются. Нужны JRE 21, ECJ 3.38 (файл `tools/ecj.jar`), Android SDK platform 35 и Android build-tools 35. SDK следует установить в `tools/android-sdk`; путь к `android.jar` и утилитам сборки уже задан в `tools/build.sh`. Для подписи задайте переменные `KEYSTORE`, `KEY_ALIAS`, `STOREPASS` и `KEYPASS`; демонстрационный ключ в репозиторий не включён.

```
python tools/make_audio.py
bash tools/build.sh
```

Для браузерной проверки: `python -m http.server 8001 --bind 127.0.0.1 --directory app/src/main/assets`, затем `node tools/test.cjs` с установленным Playwright. Путь импорта Playwright адаптируйте к своей системе. Проверяются еда/рост/рекорд, пауза, запрет разворота, столкновение, SMS multi-tap и сохранение после перезагрузки, воспроизведение рингтона и ошибки JavaScript. Подпись APK проверяется apksigner. Результаты Android-проверки и снимки доступны в отдельном архиве проверки. Физическое устройство не тестировалось.
