# Проверка Android

Платформа: официальный Android Emulator, AOSP Android 10 / API 29, x86_64, 720×1280. Программная эмуляция CPU, SwiftShader GPU. Это эмулятор, не физический телефон.

План проверки финального APK:
1. Установка ADB и холодный запуск Activity из установленного APK.
2. Пиксельное меню: отсутствие страницы ошибки WebView и ошибок JavaScript.
3. Запуск Змейки, движение, очки и пауза через экранные кнопки.
4. Ввод SMS цифровыми кнопками и клавиатурой Android. Сохранение черновика, принудительное завершение процесса, повторный запуск и проверка текста.
5. Воспроизведение рингтона с движением спектра; проверка AudioFlinger и захвата WAV из аудиовыхода эмулятора.
6. Домой/недавние приложения/возврат в приложение. Проверка журнала Android на падения процесса.
7. Запись системного экрана Android, включая запуск APK и системную клавиатуру. Проверка итогового MP4.

Фактические результаты и команды сохраняются отдельно в build/android-validation.txt. Этот файл содержит план, а не утверждение о пройденных проверках.
